# 锐满分教育（金御花园）· 咸水沽5公里基础教育全景可视化地图

本可视化交互系统专为**天津市津南区咸水沽镇金御花园「锐满分教育」**量身定制，覆盖校区周边5公里半径内的各居民小区、公办小学、对口初中、重点高中以及全链路升学率与招考数据。

## 一、核心功能亮点
1. **5KM 阶梯辐射圈交互**：
   - 🟢 **1KM 步行核心圈**：金御花园、金才园、金浩园、世纪佳园、吾悦华府、城市亮点、艺树澜庭等（直属对口咸水沽六小）。
   - 🔵 **3KM 黄金拓展圈**：富力又一城（合祥/合力/合茂等，对口津南实验小学）、博雅/滨河（对口五小）、惠丰/米兰（对口三小）、月坛商圈（对口四小）。
   - 🟣 **5KM 战略辐射圈**：海河教育园区南开学校（享六区中考特权）、双桥河镇。
2. **升学全链路一键透视**：
   - 点击任意小区，系统动态绘制：`居民小区` ➔ `对口划片小学` ➔ `第二学区初中派位（咸二中/咸四中/咸五中/咸三中）` ➔ `终极目标高中（咸一中 717.3分 / 咸二中 670分）`。
3. **初高中中考升学硬核数据**：
   - 包含津南区中考普高率（50.8%分流红线）、各初中普高率排行榜、咸一中高分达线率。
4. **锐满分教育专属拓客与面咨作战室**：
   - 内置针对周边各校（六小、实验小学、五小、四小、初二分化生、初三冲刺）的家长痛点话术与课程转化方案。
